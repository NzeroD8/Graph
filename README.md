# Визуализатор графа зависимостей пакетов (CLI)

Консольный инструмент визуализации графа зависимостей пакетов
менеджера apt (Ubuntu).

## Общее описание

Приложение написано на Python и использует только стандартную
библиотеку. Менеджеры пакетов и сторонние библиотеки для получения
зависимостей не применяются: Параметры работы задаются опциями командной строки.

## Этап 1. Минимальный прототип с конфигурацией

На этом этапе реализовано настраиваемое CLI-приложение:
- разбор опций командной строки;
- проверка каждого параметра с понятным сообщением об ошибке;
- вывод всех параметров в формате «ключ: значение».

Если параметров несколько и все неверны, сообщения об ошибках
выводятся вместе, каждое на своей строке с префиксом `Ошибка:`.

## Функции и настройки

| Опция               | Описание |
|---------------------|---|
| `--package`         | Имя анализируемого пакета (обязательна) |
| `--repo`            | URL репозитория или путь к файлу тестового репозитория (обязательна) |
| `--test-mode`       | Флаг: `--repo` указывает на файл тестового репозитория |
| `--package-version` | Версия пакета (обязательна) |
| `--output`          | Имя файла с изображением графа, по умолчанию `graph.svg` |
| `--ascii-tree`      | Флаг: выводить зависимости в виде ASCII-дерева |
| `--filter`          | Подстрока для фильтрации пакетов  |

Правила проверки:

- `--package`: в обычном режиме - строчные латинские буквы, цифры и
  символы `+ - .`, не короче двух символов, первый символ - буква или
  цифра; в режиме тестирования - заглавные латинские буквы;
- `--repo`: в обычном режиме - URL вида `http(s)://путь`; с
  `--test-mode` - существующий читаемый файл;
- `--package-version`: начинается с цифры, допускаются (`2:`),
  буквы, цифры и символы `. + ~ -`;
- `--output`: только имя файла с расширением `.svg`;
- `--filter`: латинские буквы, цифры и символы `+ - .`.

## Сборка и запуск

Запуск приложения:

```powershell
python src/main.py --package nginx --repo https://archive.ubuntu.com/ubuntu --package-version 1.24.0-2ubuntu7
```

Скрипт `run.bat` запускает приложение и передаёт ему все аргументы:

```bat
run.bat --package nginx --repo https://archive.ubuntu.com/ubuntu --package-version 1.24.0-2ubuntu7
```

## Примеры использования

Обычный режим со всеми параметрами:

```
$ python src/main.py --package nginx --repo https://archive.ubuntu.com/ubuntu --package-version 1.24.0-2ubuntu7 --output deps.svg --ascii-tree --filter lib
package: nginx
repo: https://archive.ubuntu.com/ubuntu
test_mode: false
version: 1.24.0-2ubuntu7
output: deps.svg
ascii_tree: true
filter_substring: lib
```

Ошибки параметров:

```
$ python src/main.py --package Nginx --repo ftp://host/ubuntu --package-version 1.0 --output graph.png
Ошибка: --package: имя «Nginx» недопустимо: нужны строчные латинские буквы, цифры и символы + - . (не короче двух символов, первый символ - буква или цифра)
Ошибка: --repo: «ftp://host/ubuntu» не похоже на URL: ожидается вид http(s)://путь (для файла тестового репозитория добавьте --test-mode)
Ошибка: --output: имя «graph.png» недопустимо: нужно имя файла с расширением .svg
```

Режим тестирования (файл репозитория должен существовать):

```
$ python src/main.py --package A --repo README.md --test-mode --package-version 1.0
package: A
repo: README.md
test_mode: true
version: 1.0
output: graph.svg
ascii_tree: false
filter_substring: (не задано)
```

Скрипт `scripts\1_part.bat` демонстрирует корректные запуски и обработку
ошибок для всех параметров.

## Тестирование

Тесты модулей `config.py` и `main.py` находятся в каталоге `tests/`.

Запуск всех тестов:

```powershell
python -m unittest discover -s tests -v
```
